Pseudo-classe   Exemplos                                                     Descrição

:activea:       active                                     Seleciona o link que está ativo no momento do clique.

:any-link       a:anylinkarea                              Seleciona qualquer elemento <a> ou <area> que possua um atributo href.    
                :anylink                                 
               
               
autofill        :auto-fillinput:                           Seleciona elementos <input> preenchidos automaticamente pelo navegador.

:checked        input:checkedoption:                     checkedSeleciona elementos <input> ou <option> que estão marcados/selecionados.


:defaultinput   :defaultbutton                           Seleciona elementos de formulário que são os padrões em um grupo de elementos relacionados.
                :defaultoption
                :default
                

 :defined       :defined                                Seleciona qualquer elemento que tenha sido definido (elementos padrão ou customizados).
 
 
 :dir()         :dir(ltr)                                 Seleciona elementos com base na direção do texto especificada (ltr = esquerda para direita, rtl = direita para esquerda).
                :dir(rtl)
                
:disabled:      disabled                                  Seleciona elementos desabilitados. Usado principalmente em formulários.
                input:disabledoption
                :disabled
                
:empty          div:empty                                Seleciona elementos que não possuem filhos (incluindo nós de texto).


:enabled        :enabledinput:enabled                     Seleciona elementos habilitados. Usado principalmente em formulários.


:first          @page:first                                Representa a primeira página de um documento impresso (usado com a regra @page).

:first-child    p:first-child                          Seleciona o elemento que é o primeiro filho do seu elemento pai.
                li:first-child            
                

:first-of-type  p:first-of-type                       Seleciona o primeiro elemento do seu tipo entre um grupo de elementos irmãos.
                li:first-of-type
                
:focus          input:focus
                select:focus                           Seleciona o elemento que recebe foco. Usado principalmente em formulários.
                
:focus-visible  button:focus-visible                  Seleciona o elemento focado apenas quando o foco é feito via teclado (e não pelo mouse).

:focus-within       form:focus-within                 Seleciona um elemento se ele ou qualquer um de seus descendentes receber foco.
                    label:focus-within    


 :fullscreen        :fullscreen                       Seleciona qualquer elemento que esteja atualmente no modo tela cheia.
                    
                  
                    
:has()              h2:has(+p)                       Seleciona elementos <h2> que são seguidos imediatamente por um <p>, aplicando o estilo ao <h2>.


:hover              a:hover                        Seleciona o elemento quando o ponteiro do mouse passa sobre ele.
                    p:hover 
                    
                    

:in-range          input:in-range                    Seleciona elementos <input> cujo valor está dentro dos limites especificados.


:indeterminate      input:indeterminate               Seleciona elementos de formulário em um estado indeterminado (ex: checkbox não marcado e nem desmarcado explicitamente via JS).


:invalid	        input:invalid                  Seleciona elementos de formulário com valores inválidos.
                    fieldset:invalid


:is()	            :is(ul, ol)	                  Seleciona elementos que correspondem a qualquer um dos seletores da lista   (ex: todos os <ul> e <ol>).


:lang()	            p:lang(it)	                  Seleciona elementos <p> com o atributo lang igual ao idioma especificado (ex: "it" para italiano).



:last-child	       li:last-child	               Seleciona o elemento que é o último filho do seu elemento pai.


:last-of-type	  p:last-of-type	              Seleciona o último elemento do seu tipo dentro do seu elemento pai.

:left	          @page :left	                 Representa todas as páginas da esquerda em um documento impresso (usado com a regra @page).


:link	          a:link	                       Seleciona todos os links que ainda não foram visitados.


:modal	              :modal	                   Seleciona um elemento que está em um estado modal (ex: <dialog> aberto com .showModal()).


:not()	             :not(p)	                   Seleciona qualquer elemento que não corresponda ao seletor especificado.


:nth-child()	    p:nth-child(2)	               Seleciona o elemento que é o N-ésimo filho de seu elemento pai (no exemplo, o 2º filho).


:nth-last-child()	p:nth-last-child(2)	              Seleciona o N-ésimo filho de seu elemento pai, contando a partir do último.


:nth-last-of-type()	p:nth-last-of-type(2)       	Seleciona o N-ésimo elemento do mesmo tipo, contando a partir do último.


:nth-of-type()	p:nth-of-type(2)	               Seleciona o N-ésimo elemento do seu tipo dentro do elemento pai.
